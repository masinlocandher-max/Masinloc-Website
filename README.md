# Masinloc, Zambales — deploy package

Static production-ready website. No build step and no external JavaScript dependencies.

## Deploy

### Vercel
Upload this folder or ZIP as a new project. Framework preset: **Other**. Build command: **none**. Output directory: **`.`**.

### Netlify
Drag the folder/ZIP into Netlify Drop or connect it to a repository. Publish directory: **`.`**.

### Any web host
Upload `index.html`, the CSS files, `app.js`, and the `assets/` folder to the public web root.

## Content notes

- Core values are locked as: `Milalabi — Magmahalan`, `Mitatambay — Magtulungan`, `Miasasa — Magkaisa`.

The blue-yellow-red identity and the values Milalabi / Mitatambay / Miasasa remain unchanged.
