# UX polish verification checklist

- [ ] Home hero remains one exact approved AVIF asset.
- [ ] Desktop navigation transitions to a readable sticky/fixed surface after scroll.
- [ ] Mobile navigation remains accessible and closable with Escape.
- [ ] Reveal animations never hide content without JavaScript.
- [ ] `prefers-reduced-motion` disables non-essential motion.
- [ ] A Closer Look, Verified History, and Masinloc Bulletin use the same public polish layer.
- [ ] Masinloc Connect uses the modern override layer without changing app logic.
- [ ] Form controls remain keyboard-focus visible and touch friendly.
- [ ] No unfinished future-stage routes are exposed.
- [ ] Site integrity workflow passes before merge.
